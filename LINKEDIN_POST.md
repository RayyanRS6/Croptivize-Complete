## Project Details Summary (For Reference)

### Technical Architecture
- **Frontend:** React 19, Vite, Tailwind CSS 4.0, Redux Toolkit, React Router v7
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT, Passport.js (Google OAuth)
- **ML Service:** Flask, PyTorch, ResNet9 architecture
- **Storage:** Cloudinary (image hosting)
- **APIs:** Plant.id (plant validation), OpenWeatherMap (weather data)
- **Deployment:** Vercel (frontend & backend)

### Disease Detection Model
- **Architecture:** ResNet9 (Custom CNN)
- **Classes:** 6 cotton diseases (Aphids, Army Worm, Bacterial Blight, Healthy, Powdery Mildew, Target Spot)
- **Input:** 256x256 RGB images
- **Output:** Disease classification with confidence scores

### Features Breakdown
1. **Disease Detection**
   - Image upload or camera capture
   - Plant validation via Plant.id API
   - Disease classification with treatment recommendations
   - Chemical, biological, and prevention strategies

2. **Fertilizer Calculator**
   - Supports 10+ crop types
   - Field area calculation (rectangle, circle, triangle)
   - NPK recommendations in kg/ha
   - Application method suggestions

3. **E-Commerce Shop**
   - Product catalog (Fertilizers, Tools, Seeds, Pesticides, Equipment)
   - Advanced filtering (category, price, rating)
   - Search functionality
   - Pagination

4. **Farming Guide**
   - General farming practices
   - Seasonal care tips
   - Pest control strategies
   - Fertilizer management
   - Real-time weather data

5. **User Management**
   - Registration/Login
   - Google OAuth integration
   - Admin dashboard
   - Order management
   - Disease history tracking

### Database Models
- User (with roles: user, admin)
- Product (with categories, ratings, pricing)
- Order (order management)
- Disease (disease detection history)
- Message (contact form submissions)
